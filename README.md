## 📌 Featured Projects

### 🔔 [native-school-dash](https://github.com/daltonharrold/native-school-dash): JBS Dash
A native **SwiftUI** app for **iPhone, Apple Watch, and Mac** that answers one question fast: *how much time is left in this period?*
- Live countdown ring that understands rotating bell schedules and passing periods
- Home Screen, Lock Screen, and watch-face **widgets** with timelines pre-computed for the whole school day
- Offline-first: 7 days of schedules cached in **Core Data**, synced with **CloudKit**, and refreshed by a background task
- Six targets across iOS, watchOS, and macOS sharing one model and persistence layer

`Swift` `SwiftUI` `WidgetKit` `Core Data` `CloudKit`

### 🔥 [fireship](https://github.com/daltonharrold/fireship)
Two full-stack **Next.js 13** apps built with the App Router and React Server Components:
- **myspace**: a MySpace-style social network with GitHub OAuth, editable profiles, and following (NextAuth, Prisma, PostgreSQL)
- **crudapp**: a notes app exploring server-side fetching, caching, and revalidation (PocketBase)

`TypeScript` `Next.js` `NextAuth` `Prisma` `PostgreSQL`

### 🎓 [cs50-submissions](https://github.com/daltonharrold/CS50-Submissions)
